# 면접 준비와 STAR 답변 가이드

> 행동면접은 과거 경험을 통해 직무 수행 방식을 확인한다. STAR는 답을 완전한 이야기로 구조화하는 도구다.


## 1. STAR 구조

- **S — Situation**: 어떤 상황이었는가?
- **T — Task**: 본인이 맡은 목표나 책임은 무엇이었는가?
- **A — Action**: 본인이 실제로 무엇을 했는가?
- **R — Result**: 결과, 검증, 배운 점은 무엇인가?

답변의 중심은 **Action**이다. 배경 설명이 길고 본인의 행동이 짧으면 역량을 평가하기 어렵다.

### 권장 비중

- 상황: 약 20%
- 과제: 약 10%
- 행동: 약 60%
- 결과: 약 10%

이는 절대 규칙이 아니라, 행동을 충분히 설명하기 위한 연습 기준이다.

## 2. 답변 만드는 순서

1. 질문이 확인하려는 역량을 한 단어로 정의한다.
2. 그 역량을 보여주는 실제 경험을 고른다.
3. 상황과 과제를 짧게 정리한다.
4. 행동을 시간 순서 또는 판단 순서로 설명한다.
5. 결과를 수치, 변화, 피드백, 학습으로 마무리한다.
6. 지원 직무에서 어떻게 활용할지 한 문장으로 연결한다.

## 3. 스토리 뱅크

질문마다 답을 새로 외우기보다 경험 이야기 묶음을 준비한다.

- 협업
- 갈등 해결
- 실패와 회복
- 문제 해결
- 우선순위 조정
- 학습과 적응
- 주도성
- 고객 또는 사용자 대응

하나의 경험은 질문에 따라 강조점을 바꿔 재사용할 수 있다. 단, 질문과 무관한 이야기를 억지로 끼우지 않는다.

## 4. 좋은 Action 설명

- `우리가 했다`만 반복하지 않고 본인의 행동을 밝힌다.
- 판단 근거, 선택지, 실행 순서, 검증 방식을 설명한다.
- 팀원 기여를 지우지 않으면서 본인 책임을 구분한다.
- 기술 이름을 나열하기보다 문제를 해결한 과정을 말한다.

## 5. Result가 약할 때

큰 성과가 없어도 다음을 사용할 수 있다.

- 오류나 위험을 발견한 것
- 작업 시간이 줄어든 것
- 재현 가능한 문서나 테스트를 만든 것
- 사용자 또는 팀원의 피드백
- 실패 원인을 파악하고 다음 방식으로 바꾼 것
- 본인이 배운 원칙과 이후 적용 사례

결과를 꾸며내는 것보다, 한계를 인정하고 검증 가능한 변화를 말하는 편이 낫다.

## 6. 1분 자기소개 구조

1. 현재 목표 직무
2. 그 직무와 연결되는 대표 경험
3. 확인 가능한 강점 또는 성과
4. 지원한 역할에서 기여하고 싶은 방향

연대기를 길게 읽거나 이력서를 그대로 반복하지 않는다. 보통 1~2분 안에서 핵심이 전달되도록 연습한다.

## 7. 연습 방법

- 답변을 글로만 쓰지 말고 소리 내어 말한다.
- 녹화하여 말의 길이, 시선, 자세, 반복 표현을 확인한다.
- 동료와 모의면접을 하고 `무슨 역량이 보였는지` 피드백을 받는다.
- 답변을 통째로 암기하기보다 핵심 단어와 흐름을 익힌다.
- 예상 꼬리질문을 준비한다: 왜 그렇게 판단했는가, 다른 방법은 없었는가, 본인 기여는 무엇인가, 다시 한다면 무엇을 바꿀 것인가?

## 8. 상담 응답 규칙

- 실제 경험을 듣지 않고 모범답안을 완성해주지 않는다.
- 사용자의 경험을 과장하거나 허위 성과를 추가하지 않는다.
- 특정 회사의 최신 면접 방식은 공식 채용 페이지나 현재 전형 안내를 확인한다.
- 차별적이거나 지나치게 사적인 질문에는 답변 범위를 스스로 선택할 수 있음을 안내한다.
