# 취업 준비 로드맵

> 취업 준비는 직무 선택, 근거 만들기, 서류, 지원, 면접, 회고를 반복하는 과정이다.


## 1. 현재 단계 진단

다음 중 어디에서 막혀 있는지 먼저 확인한다.

- 목표 직무가 정해지지 않음
- 목표는 있으나 요구역량을 모름
- 경험과 프로젝트가 부족함
- 이력서와 포트폴리오가 정리되지 않음
- 지원은 하지만 서류 통과가 적음
- 면접에서 경험 설명이 어려움
- 최신 채용정보와 자격 요건을 찾기 어려움

## 2. 단계별 로드맵

### 1단계 — 목표 직무 좁히기

- 관심만이 아니라 실제 업무, 필요한 지식·기술·태도, 업무환경을 확인한다.
- 유사한 직무 2~3개를 비교한다.
- NCS와 커리어넷은 직무 기준과 직업 정보를 확인하는 출발점으로 활용한다.

### 2단계 — 공고 분석

- 여러 공고에서 반복되는 업무와 기술을 찾는다.
- 필수와 우대를 구분한다.
- 회사별 표현보다 공통 과업을 먼저 추출한다.
- 공고 수와 경쟁률은 시점에 따라 변하므로 현재 자료를 사용한다.

### 3단계 — 역량 근거 만들기

- 교육, 프로젝트, 현장경험, 봉사, 개인작업을 직무요건과 연결한다.
- 근거가 없는 핵심 역량은 작은 과제나 프로젝트로 보완한다.
- 완성도보다 문제·역할·검증이 분명한 결과물을 만든다.

### 4단계 — 서류와 포트폴리오

- 공고별로 관련 경험의 순서와 표현을 조정한다.
- 이력서 문장을 PAR로 정리한다.
- 포트폴리오는 대표 사례 중심으로 구성한다.
- 링크와 제출 파일을 점검한다.

### 5단계 — 지원과 기록

- 지원 회사, 직무, 공고 원문, 제출 문서, 결과, 피드백을 기록한다.
- 탈락 원인을 하나의 추측으로 단정하지 않는다.
- 일정한 표본이 쌓이면 서류·면접 단계별 문제를 구분해 개선한다.

### 6단계 — 면접

- 직무기술서와 공고에서 예상 역량을 뽑는다.
- STAR 스토리 뱅크를 준비한다.
- 회사와 직무를 조사하고 질문할 내용을 준비한다.
- 모의면접과 녹화로 말하기를 검증한다.

### 7단계 — 회고와 반복

- 어떤 공고에서 반응이 좋았는지 확인한다.
- 서류 표현 문제인지, 근거 부족인지, 목표 직무 불일치인지 분리한다.
- 새로운 자격이나 기술을 무조건 추가하기 전에 실제 병목을 찾는다.

## 3. 상담 답변의 우선순위

1. 사용자 상황을 확인한다.
2. 가장 큰 병목 하나를 고른다.
3. 오늘 할 수 있는 행동을 제시한다.
4. 확인 가능한 산출물 기준을 정한다.
5. 최신 정보가 필요하면 공식 경로로 분리한다.

## 4. 최신 정보 확인 경로

- **채용공고·구인정보**: 고용24와 기업 공식 채용 페이지
- **직무역량**: NCS 직무정보와 실제 직무기술서
- **직업 탐색**: 커리어넷 직업정보
- **국가자격 일정·응시자격**: Q-Net
- **공공기관 채용**: 해당 기관 공식 채용 공고와 공공기관 채용 시스템

## 5. 상담 응답 규칙

- 지원 횟수나 준비 기간을 모든 사용자에게 동일하게 강요하지 않는다.
- 사용자의 경제상황, 일정, 경력단계, 지역을 확인하지 않고 장기 계획을 단정하지 않는다.
- `자격증을 따면 취업된다`, `이 기술은 필수다`처럼 인과를 과장하지 않는다.
- 계획은 행동과 결과물 기준으로 제시한다.
