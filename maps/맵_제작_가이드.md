## 0. 폴더 규칙 — slug로 통일

```
maps/<시나리오 slug>/
  <slug>.png        ← 배경 (1920×1080 고정)
  <slug>.tmx        ← Tiled 작업 파일  ← 내가 만드는 것
  geometry.json     ← 변환 결과 (게임이 읽음)   ┐
  review.csv        ← 좌표 검수용 (엑셀)        ├ 스크립트가 생성
  debug-overlay.html← 레이어 시각 확인          │
  playtest.html     ← 걸어보기 (검증용)         ┘
```

- `data/maps/scenario_map.yaml`은 `slug: slug` 형태 (이미 30장 연결됨). **새로 맵을 만들면 여기 null만 바꾸면 된다.**
- geometry.json·PNG를 제외한 산출물은 언제든 재생성 가능 (git에는 PNG 제외하고 올라감)

## 1. Tiled 레이어 4종

### 화면은 카메라가 따라온다 — 그림 전체를 써도 된다

게임 화면은 **1.25배로 확대되고 카메라가 플레이어를 따라 움직입니다** (2026-07-20 팀 확정).
아래로 걸어가면 화면이 같이 내려가므로, **배경 1920×1080 전체를 무대로 쓸 수 있습니다.**

- `walkable`은 **그림에서 실제로 걸을 수 있는 바닥**에 맞춰 그린다 (사각형 1~수 개)
- **`walkable`의 첫 사각형이 좌표 원점**이 되므로, 가장 왼쪽·위를 덮는 것을 첫 번째로 둔다
- NPC 자리·플레이어 시작 위치는 그림 어디든 가능 (걸어서 도달만 되면 된다)
- 캐릭터는 **한 번에 한 방향으로만** 걷는다 (대각선 없음) — 좁은 통로도 지나갈 수 있게 설계

| 레이어 | 타입 | 그리는 것 |
|---|---|---|
| `background` | 이미지 | `<slug>.png` 불러오기 |
| `walkable` | 오브젝트 | 걸을 수 있는 바닥 (사각형 1~수 개 — 첫 번째가 좌표 원점) |
| `collision` | 오브젝트 | 통과 불가 — 가구 몸통·벽. 사각형 또는 **폴리곤**(대각선 구조물) |
| `overhead` | 오브젝트 | 캐릭터를 가릴 가구 상단부 (아래 §3) |
| `spawns` | 오브젝트(점) | `player` + NPC 자리 (아래 §4) |

캔버스 1920×1080 · 그리드 24px (80×45).

## 2. collision — 몸이 파고들지 않게

**가구 몸통 전체**를 막는다. 뒤쪽 경계는 가구의 뒤 가장자리에 둔다.

- ❌ 발치 띠만 막기 → 캐릭터가 책상 속으로 절반 넘게 들어감
- ✅ 몸통 전체 막기 → 가구 뒤에 서면 상반신만 보이는 자연스러운 깊이감
- 화분처럼 잎이 퍼진 가구는 **화분(pot) 폭만** 막는다 — 잎 폭까지 막으면 멀찍이서 안 지나가짐
- 통로 폭은 캐릭터 발판(46px)이 지나가야 하므로 **최소 2칸(48px), 권장 3칸(72px)**
- 대각선 구조물은 폴리곤(P키, 점 찍고 Enter)으로 딴다 — 컨버터가 `collision_polys`로 내보내고 게임이 point-in-polygon으로 판정한다

## 3. overhead — 가려짐(오클루전) 🆕

캐릭터가 가구 **뒤**에 서면 하반신이 가려지는 효과. 게임이 배경의 그 영역만 잘라서 캐릭터 위에 다시 그린다.

**판정 규칙**: 오브젝트의 **밑변 y = baseline**. 캐릭터 발이 baseline보다 **위**면 가려지고, **아래**면 캐릭터가 앞에 그려진다. → **밑변을 가구가 바닥에 닿는 선에 맞춰야 한다.**

### 타이트함 3단계 — 가구 모양에 맞춰 고른다

| 방식 | 쓰는 곳 | 하는 법 |
|---|---|---|
| ① 사각형 | 윤곽이 네모난 가구 (캐비닛, 책장) | R키로 사각형 |
| ② 폴리곤 | 비스듬하거나 ㄱ자 윤곽 | P키로 점 찍고 Enter |
| ③ 픽셀 마스크 | 모니터+케이블처럼 틈새가 많은 가구 | 아래 절차 |

> ⚠️ **오탐 주의**: 오클루더 영역에 '그냥 바닥' 픽셀이 들어가면, 그 바닥을 지날 때 캐릭터가 잘려 보인다(팀장님 지적사항). 폴리곤도 틈새 바닥을 1~2px 물 수 있으므로 복잡한 가구는 마스크를 쓴다.

### 픽셀 마스크 만들기

```bash
python tools/map-geometry/make-occluder-mask.py \
  maps/<slug>/<slug>.png  <x> <y> <w> <h>  maps/<slug>/mask_<이름>.png
```

- x,y,w,h = 그 가구를 감싸는 대략적인 사각형 (Tiled에서 읽으면 됨)
- 만들어진 마스크를 Tiled에서 **사각형 오브젝트에 커스텀 속성**으로 연결: 이름 `mask`, 값 `mask_<이름>.png`
- 판별이 애매하면 표본 좌표를 뒤에 덧붙일 수 있다: `... mask.png 900,375 950,370` (바닥 픽셀 위치)
- 오차는 항상 가구 안쪽으로 나게 처리돼 있어, **바닥을 무는 실수(오탐)는 나지 않는다**

## 4. spawns — NPC 자리 수는 시나리오마다 다르다

점(Point) 오브젝트로 찍고, 이름을 정확히 아래대로 준다:

```
player      ← 플레이어 시작 위치 (주 출입구 안쪽, 사방이 열린 곳)
teamjang    ← 1번째 NPC 자리
sasu        ← 2번째
bujang      ← 3번째
npc4        ← 4번째 (필요한 맵만)
npc5        ← 5번째 (필요한 맵만)
```

- **필요한 개수만 찍으면 된다.** 백엔드는 맵에 실제로 있는 자리만 사용한다 (없는 자리는 알아서 앞 자리로 순환).
- 자리는 서로 **130px 이상** 떨어뜨린다 (근접 대화 반경). 각 자리는 걸어서 도달 가능해야 한다.
- 자리 수 표는 §6.

## 5. 작업 절차 (맵 1장)

1. **Tiled에서** `maps/<slug>/<slug>.tmx` 새로 만들고 배경 이미지 레이어 추가
2. walkable → collision → overhead → spawns 순으로 그리기
3. 복잡한 가구는 마스크 생성(§3) 후 `mask` 속성 연결
4. **변환**:
   ```bash
   python tools/map-geometry/tiled-to-geometry.py maps/<slug>/<slug>.tmx
   ```
5. **검증** — `maps/<slug>/playtest.html`을 브라우저로 열어 직접 걸어본다
   (실제 게임에서 확인하려면 `http://localhost:5173/scenario?slug=<slug>`)
   (`cd maps/<slug> && python -m http.server` 후 접속)
   - **G키**: 충돌 영역 표시 · **O키**: 오클루더 윤곽·이름표
   - 확인 항목: §7 체크리스트
6. `data/maps/scenario_map.yaml`에서 해당 slug의 `null` → `<slug>`로 변경 (이미 연결돼 있으면 생략)
7. 커밋 (PNG는 .gitignore로 제외됨 — geometry.json·tmx만 올라감)

## 7. 완성 체크리스트 (playtest에서 확인)

- [ ] **도달성**: 모든 방·구역에 실제로 걸어서 들어가진다 (막힌 구역 0)
- [ ] **통로**: 좁은 길목도 막힘 없이 통과된다
- [ ] **오클루전**: 가구 뒤에 서면 하반신이 가려지고, 앞에 서면 전신이 보인다
- [ ] **오탐 없음**: 가구 주변을 한 바퀴 돌며 — **그냥 바닥인데 몸이 잘리는 지점 0**
- [ ] **파고듦 없음**: 가구에 다가갔을 때 몸이 절반 넘게 파묻히지 않는다
- [ ] **spawn**: 자리 수가 §6과 맞고, 각 자리에 도달 가능하며, 시작 위치에서 갇히지 않는다
      (갇히면 playtest 상단에 ⚠ 경고가 뜬다)

## 8. 자주 겪은 함정

- **폴리곤이 좌표에 안 나온다** → 예전 컨버터 버그였고 지금은 고쳐져 있다. 안 나오면 레이어 이름(`collision`/`overhead`) 확인.
- **오클루더가 배경과 어긋나 이중으로 보인다** → 오브젝트 좌표가 실제 가구 위치와 다름. debug-overlay.html로 확인.
- **캐릭터가 시작하자마자 못 움직인다** → player spawn이 collision 안. playtest 상단 경고 참고.
- **색 기반 자동 누끼는 초안까지만** — 전체 자동 트레이스는 실패했다(오탐 다수). 마스크는 가구 하나씩 좌표를 주고 뽑는 용도로 쓴다.
