# 차량·기계 정비 보조 — 정비소 신입 업무 지식

[차량·기계 정비 보조/장비·상태점검형] 정비 착수 전 확인: 작업지시서의 차량번호·작업항목을 실제 차량과 대조해 다른 차량을 작업하는 사고를 방지한다. 리프트 사용 시에는 고임목을 설치하고 리프트 4점 지지 상태를 확인한 뒤에 승강한다. 확인 없이 승강하면 차량 낙하 사고로 이어진다.

[차량·기계 정비 보조/장비·상태점검형] 엔진오일 교환 절차: 차종 정비지침서에서 오일 규격·용량·드레인플러그 규정토크를 확인한다(예: 특정 차종 0W-20, 3.6L, 35N·m처럼 차종마다 값이 다르므로 기억에 의존하지 말고 반드시 해당 차종 지침서를 확인). 오일량·누유·드레인플러그 상태를 점검해 기록하고, 폐유는 지정용기에 처리하며, 공구 정리 후 반장에게 검수를 요청한다.

[차량·기계 정비 보조/장비·상태점검형] 작업 우선순위 판단: 안전에 직결된 증상(브레이크 밀림 호소 등) 차량은 운행 중지를 안내하고 선임에게 즉시 공유한다 — 신입 단독 진단은 금지다. 예약 점검(조향장치 등) 준비를 차순위로, 입고 부품 검수와 완료차량 출고 준비를 후순위로 배열하고, 순서와 근거를 보고한다.

[차량·기계 정비 보조/장비·상태점검형] 가스차량(CNG 등) 위험 대응: 점검 중 가스 냄새를 감지하면 즉시 '작업 중단'을 보고하고, 시동·전원을 차단하며, 셔터를 개방해 환기한다. 화기·스파크 발생 공구 사용을 금지하고 접근을 통제한다. 임의로 배관·밸브를 조이지 않는다. 스캐너의 고장코드·연료압력 값은 읽어서 선임에게 전달하고, 선임 지시 하에 비눗물 누출검사를 보조하며 결과를 기록한다.

[차량·기계 정비 보조/장비·상태점검형] 측정과 판정 원칙: 측정 전 기준표가 해당 장비 모델용인지 확인한다 — 타 모델 기준으로 판정하면 오판이다. 유압 등은 잔압 제거를 확인한 뒤 게이지를 연결해 3회 측정값을 기록하고, 해당 모델 정비지침서의 기준값 범위와 대조해 판정한다. 기준을 모르면 임의 판정을 보류하고 선임에게 해당 모델 지침서를 요청한다.

[차량·기계 정비 보조/장비·상태점검형] 정비명세서와 인계: 차량별 작업내역과 측정값 기록지를 대조하고, 교환부품명·수량·측정 결과를 명세서 항목에 기입한다. 미완료 건은 대기 부품과 예상 일정을 명시해 인계 메모를 작성하고, 고객 설명용으로 무엇을 왜 교환했는지 한 줄 요약을 준비한다.
