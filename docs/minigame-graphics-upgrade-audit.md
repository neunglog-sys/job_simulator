# 미니게임 44종 그래픽 업그레이드·이미지 체크표

## 범위와 원칙

- 운영 대상: `data/minigames` 45개 중 개발 데모 `backend-dev-day1`을 제외한 44개
- 기능 보존: 채점, 타이머, 드래그, 클릭, 키보드, 터치, 데이터 필드는 변경하지 않음
- 적용 방식: 10개 공용 엔진 CSS와 `MiniGamePanel` 표면만 변경해 44개에 일괄 반영
- 이미지 검사 결과: 데이터에서 명시적으로 요청하는 SVG의 파일 누락은 **0건**
- 현재 보유: `apps/web/public/assets/minigames` SVG 415개

| 항목 | 기준 |

## 적용된 그래픽 개선

- 미니게임 모달을 선택된 시나리오 테마에 맞는 다크 글래스 표면으로 통일
- 공용 HUD, 타이머, 결과 패널에 깊이·광원·상태 글로우 추가
- spot: 인스펙션 렌즈, 십자 가이드, 결함 마커 깊이
- sort: 스마트 컨베이어, 카드·분류함 재질, 상태 피드백
- match: 데이터 콘솔 보드, 연결선 발광, 카드 선택 깊이
- place: 작업대·배치도 표면, 슬롯·드래그 조각 강조
- sequence: 절차 타임라인, 단계 카드·드롭존 강조
- gauge: 계측기 베젤·다이얼·바늘 광원
- physics: 리듬 트랙·밸런스·크레인 장면 깊이
- route: 지도 콘솔·노드·경로·주행 도로 광원
- trace: 정밀 작업대·가이드 밴드·절삭선 발광
- pour: 축사 작업대·구유·목표선·투입 흐름 강조
