id 이름이 곧 그려야 할 내용입니다 (예: `슬래브_개구부_덮개깨짐` = 덮개가 깨진 바닥 개구부).

## 작업 가이드

- **스타일**: 스타듀밸리풍 저해상도 도트. 게임 캔버스는 960×440 기준
- **결함(target)은 과장되게**: 도트에서 미세 차이는 안 보임 — 기움·끊김·젖음을 굵게 표현
- **함정(decoy)은 확실히 정상으로**: target과 같은 소재의 '멀쩡한 버전'이 짝으로 필요
- **얼굴 대조류**(ys-03·kts-05): 차이는 안경·모자·머리색·점 같은 굵은 특징으로만
- **글자 넣지 말 것**: 판별은 모양·색으로만 (게임 설계 원칙)
- 확대 인스펙션 뷰 전제(yg-02 세공품): 결함부를 크게 그린 확대 버전 별도
