# 미니게임 주간 카툰 배경 v3

44개 미니게임용 배경을 굵은 외곽선과 셀 셰이딩을 사용하는 주간 카툰 스타일로 구성한 세트다. 게임 로직, YAML, 캐릭터, 아이콘, UI는 변경하지 않는다.

## 파일 규격

- 경로: `apps/web/public/assets/minigames/backgrounds/cartoon-day-v3/`
- 이름: `<미니게임 ID>-background-cartoon-day-v3.webp`
- 수량: 44개
- 해상도: `1920×880`
- 형식: WebP, 품질 92
- 기존 `cartoon-v1`과 `cartoon-bright-v2`는 유지한다.

## 공통 아트 가이드

- 굵고 선명한 검은 외곽선, 읽기 쉬운 셀 셰이딩, 재질별 고유색을 사용한다.
- 일반적인 맑은 낮 조명으로 표현하되 파스텔 워시, 민트·연두색 편향, 과노출, 안개, 몽환광을 피한다.
- 장면별 색상은 통일하지 않으며 병원, 은행, 축사, 전시장 등 공간의 실제 재질과 기능을 우선한다.
- 게임 좌표가 놓이는 영역은 배경 장식과 겹치지 않도록 비우거나 낮은 디테일로 처리한다.
- 배경에 글자, 숫자, 로고, 정답 표시, 경로선, UI, 플레이 캐릭터를 넣지 않는다.

### `kts-05` 구성 기준

미니게임과 시나리오의 주 업무는 호텔 프런트 체크인이다. 만실·VIP 객실 배정, PMS 예약 조회, 여권 영문명 대조, 색상별 객실 키 전달과 인수인계 흐름을 기준으로 배경을 제작했다. 중앙과 전면은 매칭 카드·연결선·도장·객실 키 UI를 위해 비워 두었으며 로직과 YAML은 변경하지 않았다.

## 검수 기준

- 44개 미니게임 ID와 44개 WebP가 1:1 대응해야 한다.
- 모든 파일은 `1920×880`이어야 한다.
- YAML 좌표의 클릭·배치·경로 영역을 배경 오브젝트가 방해하지 않아야 한다.
- 캐릭터, 동물, 텍스트, UI는 게임 요구가 명시된 경우가 아니면 추가하지 않는다. `ms-06`의 젖소는 후면 배경 장식 예외다.

현재 폴더에는 44개 WebP가 있고 모두 `1920×880`이지만, 이번 6장 수정 이전부터 `kts-03` 한 장만 파일명이 `kts-03-background-cartoon-v1.webp`로 남아 있다. 이번 요청 범위 밖의 파일이므로 이름과 그래픽을 변경하지 않았다.
