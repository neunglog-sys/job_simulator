## 1. WER / CER — 발음 정확도

Whisper medium(재전사) 대조. **한국어는 어절 WER이 띄어쓰기에 부풀려져 CER(음절
오류율)이 주 지표**다.

| 카테고리 | 남 CER | 여 CER |
|---|---:|---:|
| 짧은 문장 (5) | **0.000** | **0.000** |
| 중간 문장 (10) | 0.014 | 0.021 |
| 긴 문장 (5) | 0.004 | 0.004 |
| 숫자·금액 (3) | 0.012 | 0.011 |
| **영문 약어 (2)** | **0.091** 🔴 | **0.061** 🔴 |
| **전체** | **0.015** | **0.015** |
| (참고) 어절 WER | 0.117 | 0.091 |

**전체 CER 1.5%** — 우수. 태수님 예측대로 **영문 약어가 최약 카테고리**다.

### 🆕 직무 용어 카테고리 (가이드 1.1 누락분 보완, 0728 추가 측정)

가이드가 명시한 **"직무 용어 별도 집계"**(POS 정산·컴플레인·온보딩 등)가 골든셋 5분류에
없어 따로 쟀다. 용어 밀도를 높인 10문장 × 남녀 = 20콜 (`TTS측정_직무용어.py`).

| | 자동 CER | **귀 확인 반영 TTS 귀속 CER** |
|---|---:|---:|
| 남성 | 5.67% | **1.62%** |
| 여성 | 5.46% | **1.18%** |

**자동 수치는 실제의 3~4배로 부풀려져 있었다.** 의심 7건을 전부 청취한 결과
**모두 TTS 정상, Whisper 오인**이었다:

| 원문 | Whisper 전사 | 판정 |
|---|---|---|
| 오제이티 | OJT | 발음대로 읽었는데 로마자로 전사 |
| 워라밸 · 순환 | 월화벨 · 순황 | TTS 정상 |
| 역량 평가 | 영양평가 | TTS 정상 |
| 자격 요건 | 작용 요건 | TTS 정상 |
| 이뤄집니다 | 이루어집니다 | 발음 동일, 표기 차이 |

⚪ **측정 방법상의 발견**: 한국어 직무 용어는 **Whisper(ASR) 쪽이 우리 TTS보다 약하다.**
자동 CER만 보고 "용어에서 터진다"고 판단했으면 오진이었다. 태수님 지적("전체 WER이
낮아도 용어에서만 몰려 터진다")은 **점검할 가치가 있었고, 점검 결과는 이상 없음**이다.

잔여 오류는 조사·띄어쓰기 수준(3.8~4.3%대 4건)이며 용어 자체 오독은 없다.
원자료 `측정데이터/tts_jobterms_0728/` (results.json에 귀 확인 결과 기록).

### 귀 확인 판정 (CER은 TTS 잘못과 Whisper 잘못을 구분 못 한다)

| 문장 | 전사 결과 | 판정 |
|---|---|---|
| s13 "직무 전환" | 남녀 동일하게 "직무 전화" | ✅ **TTS 정상** — 귀 확인 결과 "전환"으로 명확히 들림. **Whisper 오인** |
| s25 "STAR 기법" | 남: "레스트해야 할 기법" / 여: "스타일 기법" | ✅ **TTS 뭉갬 아님** — "에스티알 기법"으로 또박또박 **철자 읽기**. Whisper가 철자 읽기를 오전사 |

(귀 확인: 민수, 2026-07-28. 두 건 모두 발음 결함 아님으로 종결)

**최종 판정: TTS 발음 결함 0건.** 귀 확인 2건을 제외한 **TTS 귀속 보정 CER은
남 0.4% / 여 0.7%** — 잔여 오류도 조사·한 음절 수준의 미세 차이뿐이다
(예: s22 "6시까지이니"→유사 표기). 자동 CER 1.5%는 Whisper 오인이 포함된 상한값이다.

⚪ 결함은 아니지만 **읽기 방식 참고**: 영문 대문자 약어는 철자로 읽는다
(STAR→"에스티에이알"). 시연 대사에서 "스타 기법"으로 들리게 하려면 대본에
한글로 쓰면 된다. 강제 사항 아님 — 철자 읽기도 자연스럽게 들린다는 것이 귀 확인 결론.

## 3. 합성 안정성 (스펙트럼 재현성)

⚠️ **문헌 MCD와 직접 비교 불가** — Windows에서 SPTK/WORLD 빌드가 안 돼 MCEP 대신
**DTW 정렬 후 로그-멜 스펙트럼 평균 차이(dB)**로 측정했다. 절대값 비교는 이 표 안에서만.

| 조건 | 평균 차이 |
|---|---:|
| **같은 문장 재합성 간 (남)** | **4.58dB** (p95 5.42) |
| **같은 문장 재합성 간 (여)** | **4.52dB** (p95 5.57) |
| 베이스라인① 다른 문장 간 | 9.31dB |
| 베이스라인② 남녀 같은 문장 | 9.43dB |

재합성 변동이 콘텐츠 차이의 **절반 이하** → 같은 문장은 매번 사실상 같은 소리로
합성된다(음색·음조 왜곡 없음). 지표가 판별력이 있음은 베이스라인 2종으로 확인했다.

- ✅ 귀 확인 **총 9건 전부 완료** (s13·s25 + 직무용어 7건) — **TTS 발음 결함 0건 확정**

## 측정 한계 (정직하게)

1. **CER은 TTS 오류와 Whisper(ASR) 오류가 섞인 상한값이다.** 이번에 그 폭이 실측됐다 —
   직무 용어에서 자동 5.5% → 귀 확인 후 1.2~1.6%로, **자동 수치가 3~4배 과대평가**였다.
   한국어 전문 용어일수록 Whisper 쪽이 먼저 무너진다. **자동 CER만 보고 판단하지 말 것.**
2. 합성 안정성 지표는 자체 정의(로그-멜 dB)라 타 시스템과 수평 비교할 수 없다.
   남↔여, 카테고리 간, 시점 간 **상대 비교 전용**이다.
3. 합성 지연은 로컬→ElevenLabs 직결 값이다. 실서비스에선 코랩→ElevenLabs 구간이라
   네트워크가 다르지만, 코랩 쪽 실측(`tts_first_byte_seconds` 0.124s)과 방향이 일치한다.
