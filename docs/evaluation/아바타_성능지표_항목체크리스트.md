## 정정 이력 (스스로 틀린 것)

측정 과정에서 내가 잘못 판단했다가 바로잡은 것들. 같은 실수를 반복하지 않기 위해 남긴다.

| 내가 한 주장 | 실제 | 교훈 |
|---|---|---|
| "릴레이 connect 실패는 1011로 안 닫힌다" | **틀림** — `except`가 `websockets.connect` 전체를 감싼다. 로그 문구만 보고 코드를 안 읽었다 | **코드를 읽고 말할 것** |
| "FVD는 원리적으로 측정 불가" | 우리 아바타 대상으로는 맞으나, **HDTF 표준 벤치마크로 우회 가능**했다 | 질문을 바꾸면 답할 수 있는 경우가 있다 |
| "여성이 남성보다 FVD 2배 이탈" | **표본 수 산물**. 71개로 맞추니 1.2배로 축소, MMD²는 반대 방향 | 비율 비교 전에 표본을 맞출 것 |
| "직무 용어 CER 5.5%로 취약" | **자동 측정의 착시**. 귀 확인 시 1.2~1.6%, Whisper가 먼저 무너진 것 | 자동 지표만 보고 판정하지 말 것 |
| "쿨다운 후 콜드 재현·한쪽만 웜업" 미측정 | 전자는 **일어날 수 없는 현상**(쿨다운은 요청 dedup), 후자는 **기존 데이터에 답이 있었다** | 측정 항목을 늘리기 전에 코드와 기존 데이터를 볼 것 |
