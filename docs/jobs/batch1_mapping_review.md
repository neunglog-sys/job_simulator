# 배치1 팀 검수표 — 매핑 확정 필요 5건

- 대상: `backend-developer`, `marketer`, `j004`(문서관리 담당), `j011`(구매사무 보조),
  `j012`(발주관리 담당) — 나머지 9건은 조사 담당(연구) 선에서 잠정 확정 완료
  (`docs/jobs/batch1_mapping_candidates.md` Section A 참고).
- 출처: 워크피디아(wagework.go.kr) `retrieveOccpNvgtEdcData.do` /
  `retrieveOccpNvgtWageData.do`. 조회일: 2026-07-13.
- **"상세 데이터 상태" 용어 정의(3단계, 혼동 금지)**
  - `검색 API 0건`: 키워드 검색 색인에서만 조회되지 않음. **공식 직업사전에 해당
    항목이 없다는 뜻이 아님** — 상세 API를 코드로 직접 조회하면 데이터가 있을 수
    있음(K000001069 사례 참고).
  - `상세 API 공백`: 코드로 상세 API를 직접 호출해도 성공(`success:true`)하지만
    `edcInfo`/`wageInfo` 내부 필드가 전부 비어있음/0/null. 공식 항목 자체는
    존재하나, 학력·자격·임금 조사가 이뤄지지 않은 직업.
  - `상세 API 정상`: 공식 항목이 존재하고, 학력·자격·임금 조사 데이터도 실제로
    채워져 있음.
- 임금 컬럼은 **재직자 약 30명 설문조사 기준 중위값**이며 **신입 초임이 아님** —
  참고 통계로만 활용.
- 각 직무마다 후보 중 **정확히 1개만 "권장"**으로 표시했습니다. 팀은 (a) 권장안
  승인 또는 (b) 대안 후보 지정, 둘 중 하나만 선택하면 됩니다.
