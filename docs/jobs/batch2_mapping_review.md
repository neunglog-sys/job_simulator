# 배치2 팀 검수표 — 매핑 확정 필요 39건

- 대상: j013~j099, j100~j103 범위(총 91건) 중 조사 담당 선에서 후보가 2개 이상
  경합하거나(우열을 가리기 어려움), 유의미한 후보를 아예 찾지 못했거나, 직급/업무
  범위가 뚜렷이 불일치하는 39건. 나머지 52건은 조사 담당(연구) 선에서 잠정 확정
  완료(`docs/jobs/batch2_mapping_candidates.md` Section A 참고, YAML 파일에도 이미
  반영됨).
- 출처: 워크피디아(wagework.go.kr) 검색 API `retrieveOccpSrchKwrdListData.do`,
  일부는 한국직업사전 상세 API `retrieveOccpDctnDtalData.do`(dtyCn=직무개요)로
  후보 간 업무 정의를 대조. 조회일: 2026-07-13.
- **"상세 데이터 상태" 용어 정의(3단계 + 미확인, 혼동 금지)**
  - `검색 API 0건`: 키워드 검색 색인에서만 조회되지 않음. **공식 직업사전에 해당
    항목이 없다는 뜻이 아님** — 상세 API를 코드로 직접 조회하면 데이터가 있을 수
    있음.
  - `상세 API 공백`: 코드로 상세 API(`retrieveOccpNvgtEdcData.do`/`WageData.do`)를
    직접 호출해 성공(`success:true`)했으나 `edcInfo`/`wageInfo` 내부 필드가 전부
    비어있음/0/null.
  - `상세 API 정상`: 공식 항목이 존재하고, 학력·자격·임금 조사 데이터도 실제로
    채워져 있음.
  - `미확인`: 이 39건은 매핑 자체가 확정되지 않아 조사 담당 선에서
    `retrieveOccpNvgtEdcData.do`/`WageData.do`(학력·임금 통계)를 아직 호출하지
    않았음 — 검색 API로 코드 존재만 확인한 상태. **위 3단계 중 하나로 단정하지
    않고 별도로 "미확인"으로 표기**(회귀 테스트 케이스 3 참고, 상세 API는 코드가
    존재해도 공백인 사례가 배치2에서 다수 확인되었으므로 임의 추정 금지).
- 임금 컬럼은 (조회 시) **재직자 약 30명 설문조사 기준 중위값**이며 **신입
  초임이 아님**.
- 이 문서의 후보들은 조사 담당이 "권장"을 표시하지 않았습니다 — 39건 전부 팀
  판단이 필요하다고 보아 우선순위(priority)만 매겼습니다. 상세 사유는
  `batch2_mapping_candidates.md` Section B의 각 항목 `note` 필드 참고.
