# 미니게임 픽셀 요소 교체 인벤토리

## 조사 범위

- 대상: `data/minigames`의 활성 YAML 44개
- 기준: YAML에서 현재 실제로 참조하는 비주얼 에셋
- 제외: 완성된 맵·배경 이미지, 단순 HTML 텍스트, 버튼·진행바 같은 공통 UI
- 결과: 44개 중 43개 게임에서 교체용 이미지가 필요하며, 고유 비주얼 요소는 387종이다.
- 예외: `yg-03`은 타이핑/코드 UI 게임이라 별도 픽셀 이미지가 없다.

> 아래 수량은 파일 개수 기준이다. 같은 캐릭터의 얼굴·여권·출입증, 같은 물건의 정상·불량 상태처럼 한 원화에서 파생할 수 있는 항목은 제작 단계에서 묶을 수 있다.

## 교체 시 지켜야 할 기준

1. YAML의 정답·오답·좌표·드래그 영역·충돌 영역은 바꾸지 않는다.
2. 같은 게임의 정상/불량, 원본/위조, 조건/결과 쌍은 실루엣과 카메라 각도를 동일하게 만든다.
3. 드래그 요소는 투명 여백을 일정하게 두고, 시각 중심과 클릭 중심이 어긋나지 않게 한다.
4. 작은 아이콘은 세부 묘사보다 굵은 외곽선, 명확한 형태, 한두 개의 핵심 색을 우선한다.
5. 결과물은 투명 WebP를 기본으로 하되, 브라우저 호환이나 가장자리 품질 문제가 있는 경우 PNG를 사용한다.
6. 게임 카드·버튼·진행바 같은 공통 UI는 이미지로 만들지 않고 현재 코드 기반 UI를 유지한다.
